# PCore

## Autor

Ramiro Cardona

## Descripción

PCore es una aplicación web de ecommerce dedicada a la venta de componentes de PC.

El proyecto contiene una página principal, páginas para distintas categorías de productos y formularios de inicio de sesión y registro.

Fue desarrollado utilizando HTML5 y CSS3.

La versión final también utiliza JavaScript, JSON, Fetch API, sessionStorage y localStorage.
